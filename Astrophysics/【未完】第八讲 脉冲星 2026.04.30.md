### 脉冲星类天体的观测表现
#### 根据能量来源分类
+ 转动供能
    - 射电脉冲星=正常PSR（周期1秒左右）+毫秒PSR（周期在毫秒量级）
    - X射线脉冲星
    - γ射线脉冲星
    - 如果吸积了许多大比角动量的物质，那么脉冲星会加速 -> 这被称为再加速过程
+ 吸积供能（accretion）：
    - X射线脉冲星：脉冲星的磁矩方向和角速度方向不同，外面的物质进入脉冲星磁层后发生磁冻结现象，沿着磁感线运动到磁极，引力能在X射线波段释放。因为磁极的位置与磁矩方向相同，而与角速度方向有一定夹角，所以一段时间能看到一段时间又看不到，是一种脉冲星。
    - X射线暴：对于磁场较弱的脉冲星，磁冻结效应不明显，吸积物质直接落到脉冲星表面上，在上面堆积，温度和压强增大，点燃核聚变。
        * 白矮星上面堆积物质产生核反应，这是激变变星，光学波段。
        * 脉冲星表面产生的核反应要剧烈的多，能量大，X射线波段。
+ 未明确的功能
    - 供能软X射线重复暴SGR：磁能？
    - 反常X射线脉冲星AXP：磁能？
        * 没有观察到光学伴星存在，也没有多普勒效应 -> 不是吸积供能
        * 发现X射线波段发射功率大于转动动能减小速率 -> 不是转动供能
    - 中心致密天体CCO：热能？
    - X射线暗单中子星XDINS：热能？

### 脉冲星类天体的形成
#### 诞生温度的估计
<img src="https://cdn.nlark.com/yuque/0/2026/png/2371504/1778138243534-cb70d923-13f0-4e5e-b14b-1e09f0d72f58.png" width="401" title="" crop="0,0,1,1" id="ue6709c17" class="ne-image">

+ 所有的能量都来源于引力能。
+ 零温理想电子气体对于白矮星近似很好，但是零温简并中子气对于中子星的近似很差。
    - 中子星中强相互作用不可以忽略。
+ 引力能和Fermi气体简并能数量级相同，其他的可以忽略，二者一减得到热能。
    - 热能应该和简并能引力能同数量级，而不是零。
+ 如何估算温度：
    - 使用热能与热容做比值。
    - 热容可以用零温附近费米子气体近似，索末菲展开。

#### 冷却机制
<img src="https://cdn.nlark.com/yuque/0/2026/png/2371504/1778139820820-349cce01-c1b7-4a71-b183-cc08494972fc.png" width="400" title="" crop="0,0,1,1" id="u599b57ee" class="ne-image">

+ URCA过程：名称来自于巴西赌场，描述温度较低时中微子产生方式。
    - 中子 和 质子加电子相互转化，中间会释放中微子和反中微子。
    - 这个过程类似于赌场中钱在赌徒之间相互转移，然后赌场肯定还会稍微收点钱。
+ DURCA：直接URCA过程，要求p的数密度足够大。
    - 根据能量守恒、动量守恒（动量三角形）、电中性得出。
+ MURCA：
    - 引入旁观粒子，这个时候动量守恒就不是动量三角形了，可以是四边形等等。
    - 旁观粒子可以带走一些动量，约束就没那么严苛。所以质子数密度小一点也可以发生。
+ 中微子加热机制：
    - 星系介质吸积，超新星遗迹盘吸积，引力能高效释放。
    - 转动动能产生电子对，电子对部分落到中子星上，实现极冠加热。
+ 温度再低：光子损失能量。

### 质量半径关系
<img src="https://cdn.nlark.com/yuque/0/2026/png/2371504/1778140706527-f6e9ce04-e271-4a4c-ad81-d9f483547050.png" width="399" title="" crop="0,0,1,1" id="u510a4793" class="ne-image"><img src="https://cdn.nlark.com/yuque/0/2026/png/2371504/1778140721088-45934b85-43f4-45be-b27d-fd629b64c634.png" width="401" title="" crop="0,0,1,1" id="ub316d18b" class="ne-image">

+ TOV方程：广义相对论理论体系下的理想流体静力学方程。
+ EoS：物质的状态方程。
+ 输入中心密度，代入EoS和TOV可以得到中子的质量分布。
    - 对于不同的物质假设，EoS不同，最后解出来的质量-半径关系也不同。
    - 使用简并中子气给出的关系不对，说明中子星并不满足简并中子气模型，还有不可忽略的强相互作用。
+ 中子星质量不能太小，否则难以形成。
    - 不足以提供超新星爆发能量，无法形成中子星。

+ 中子星为什么不会发生衰变？
    - 因为存在高密度的束缚电子（中子衰变产物），电子的能量较高，中子衰变的反应难以发生。
    - 所以其实外面的壳层就是用来防止中子衰变的。
