#### 宇宙学原理
+ 宇宙三维空间部分任何一点没有特殊性。
+ 本质上是一种假设，又称为“宇宙的哥白尼原理”。

### 宇宙膨胀动力学
<img src="https://cdn.nlark.com/yuque/0/2026/png/2371504/1780295015565-c83ba391-aefb-449f-b4b5-a2bc61a2813a.png" width="401" title="" crop="0,0,1,1" id="uc7fc8a6c" class="ne-image">

+ 密度和临界密度比：
    - 如果等于临界密度，是平直无限的。
    - 如果大于临界密度，是有界无边的。
    - 如果小于临界密度，是弯曲无限的。

<img src="https://cdn.nlark.com/yuque/0/2026/png/2371504/1780295575943-5c5caa0d-4602-4da6-996b-357f0e64abd9.png" width="400" title="" crop="0,0,1,1" id="u0d138194" class="ne-image">

+ $ \omega=-1 $和$ \dot \rho = 0 $是等价的，会导致加速膨胀。
    - 能量密度不随着时间演化：真空能/暗能量，它可以导致宇宙加速膨胀。
    - 一般物质，体积膨胀，物质密度减小，万有引力导致膨胀减速。
    - 其实$ \omega<-\frac{1}{3} $就可以导致宇宙加速膨胀。
+ 开始减速膨胀原因：体积小，真空少，物质还很多，物质主导导致减速膨胀。
+ 现在加速膨胀原因：体积增大，真空变多，物质还不变，真空能主导导致加速膨胀。
    - 现在：物质和暗物质总共大概占$ 30\% $，暗能量/真空能大概占$ 70\% $。
+ 尘埃宇宙：动能远远小于静能，压强接近零。

<img src="https://cdn.nlark.com/yuque/0/2026/png/2371504/1780557834075-884d0375-875d-4429-945c-0b98497f1137.png" width="400" title="" crop="0,0,1,1" id="ua671723c" class="ne-image">

+ $ p = \rho/3 $，这是光子主导宇宙
+ $ p = 0 $，这是尘埃宇宙
+ $ p < -\rho/3 $，这是暗能量主导，宇宙加速膨胀
+ 加速膨胀原因的三种描述：$ \omega<-1/3 $的物质，真空能（暗能量），宇宙学常数
    - 真空能：基态能量不为零

### 极早期宇宙真空相变
+ 时空泡沫：
    - 真空如果涨落出来东西，带有质量，会导致时空弯曲
    - 粒子的波包的典型尺度用康普顿波长描述，时空弯曲的特征尺度用史瓦西半径描述。
    - 如果涨落出来的粒子质量很大，史瓦西半径接近康普顿波长，那么时空总是被严重弯曲状态的，称为时空泡沫。
    - 这个时候能标是普朗克能标，大概是$ 10^{19}\mathrm{GeV} $的量级。
+ GR：时空是弯曲的，在除了奇点之外的地方都是光滑的。
+ 如果尺度更小一点，在普朗克尺度：时空不是光滑的，是泡沫状的。

#### 视界疑难
<img src="https://cdn.nlark.com/yuque/0/2026/png/2371504/1780561761347-b0e4c46a-6b1d-4f12-8a2a-ce51f2f7033d.png" width="400" title="" crop="0,0,1,1" id="u4f3e82d4" class="ne-image">

+ 视界疑难：宇宙年龄时间尺度内，两个不同的点本身不可能有因果关联（不存在一个点，使其未来相关域在现在之前的部分包含这两个点）。
    - 暴涨模型的解释：宇宙早期存在暴涨，使存在某个点，使其未来相关域在现在之前的部分包含这两个点。

+ 磁单极疑难：没有找到磁单极子。
    - 暴涨模型的解释：宇宙早期存在暴涨，我们现在位于某一个真空（很大）中，磁单极子位于不同真空的交界处，我们很难到达交界。

#### 宇宙的热演化历史
<img src="https://cdn.nlark.com/yuque/0/2026/png/2371504/1780562475418-2bd9b05f-c650-4380-9b64-e2baae228f5c.png" width="399" title="" crop="0,0,1,1" id="u4a15cd4d" class="ne-image">

+ 重子不对称性：重子和反重子的数量不一样。
    - 宇宙一开始正反夸克数应该是相同的，那么正反重子数应该也是相同的。
+ 重子不对称性产生条件：要求B不守恒（重子数不守恒），C和CP破缺（共轭和宇称不守恒），偏离热平衡
+ QCD相变：现在夸克都在强子内部，但是之前都是在外面单独存在即自由夸克，夸克相向强子相变化的过程称为QCD相变。
    - QCD相变又称为强子化相变。
