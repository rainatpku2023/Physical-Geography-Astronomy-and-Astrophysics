### 相对论的概念
#### 狭义相对论
+ 光锥：为刻画时空的因果特性而将时空分区
    - 类时间隔：在-+++约定下模长为负。
    - 类空间隔：在-+++约定下模长为正。
    - 类光间隔：在-+++约定下模长为零。

<img src="https://cdn.nlark.com/yuque/0/2026/png/2371504/1779080606636-41c7f6ad-5ebe-48fe-96a8-e628927ef951.png" width="401" title="" crop="0,0,1,1" id="uef13a7d9" class="ne-image">

+ 测地线：为连接两时空点的短程线

#### 广义相对论
+ 等效原理：
    - 弱等效原理（WEP）：引力与匀加速参考系力学规律等效。
    - Einstein等效原理（EEP）：引力与匀加速参考系所有物理规律等效。
+ 如何描述弯曲时空：
    - 度规张量 -> Riemann曲率张量 -> Ricci张量 -> Ricci标量。
    - 弯曲空间：Riemann曲率张量存在非零分量。
+ 运动方程：爱因斯坦场方程。

$ R_{\mu\nu} - \frac{1}{2}g_{\mu\nu}R = 8\pi G T_{\mu\nu} $

    - 其中$ T_{\mu\nu} $就是能动张量，$ R_{\mu\nu} $为Ricci张量，$ R $为Ricci标量，$ g_{\mu\nu} $为度规张量。
    - 例如，对于理想流体来说，$ T_{\mu\nu} = (\rho+p)u_{\mu} u_{\nu} + p g_{\mu\nu} $.
    - 物质告诉空间如何弯曲，空间告诉物质如何运动。

### 史瓦西时空
#### 史瓦西时空线元
<img src="https://cdn.nlark.com/yuque/0/2026/png/2371504/1779081328539-a3cb38bc-731d-4a96-bae1-c9609ab4d9aa.png" width="400" title="" crop="0,0,1,1" id="ueed4d7ab" class="ne-image">

+ 真空爱因斯坦场方程的静态球对称解：
    - 真空：$ T_{\mu\nu} = 0 $
    - 静态：Static，$ g_{\mu\nu} $任何一个分量都不显含$ t $，而且具有$ t\rightarrow -t $对称性，即$ g_{0i} =g_{i0} = 0 $。
    - 球对称：可以在球坐标下分离变量，得到$ r^2 d\Omega^2 $项。
+ 一般而言，度规$ g_{\mu\nu} $的定义为：

$ ds^2 = g_{\mu\nu}dx^{\mu}\otimes dx^{\nu} $

    - 或者简记为：

$ ds^2 = g_{\mu\nu}dx^{\mu} dx^{\nu} $

+ 在史瓦西坐标下，解为：

$ ds^2 = -\left(1-\frac{2M}{r} \right)dt^2+\left(1-\frac{2M}{r} \right)^{-1}dr^2 + r^2\left(d\theta^2+\sin^2\theta d\phi^2\right) $

    - 史瓦西坐标：等$ r $点的面积为$ 4\pi r^2 $。
    - 补齐所有单位后：

$ ds^2 = -\left(1-\frac{2GM}{rc^2} \right)c^2dt^2+\left(1-\frac{2GM}{rc^2} \right)^{-1}dr^2 + r^2\left(d\theta^2+\sin^2\theta d\phi^2\right) $

+ 奇点：$ r = 2M $（坐标奇点）；$ r = 0 $（内禀奇点）。

#### 史瓦西时空结构
<img src="https://cdn.nlark.com/yuque/0/2026/png/2371504/1779082303419-6ce3199d-c1ba-48d8-b258-513a72b96895.png" width="400" title="" crop="0,0,1,1" id="u1f73349f" class="ne-image">

+ 从无穷远观察者（史瓦西坐标）来看，坠落者永远无法穿过黑洞视界，因为他下落时间发散到了正无穷。
+ 但是这其实是因为坐标选择的不合适。
+ 在坠落者的视角（AEF坐标，超前爱丁顿-芬克斯坦坐标）来看，坠落者可以穿过黑洞视界。
    - AEF坐标的坐标变换为：

$ t' = t + 2M \ln |\frac{r}{2M}-1| $

    - AEF坐标下史瓦西时空的线元长度为：

$ ds^2 = -\left(1-\frac{2M}{r}\right)dt'^2 + \left(1+\frac{2M}{r}\right)dr^2 +\frac{4M}{r}dt'dr+ r^2\left(d\theta^2+\sin^2\theta d\phi^2\right) $

<img src="https://cdn.nlark.com/yuque/0/2026/png/2371504/1779082510743-ba050582-1e3c-411e-8010-d29fc734171a.png?x-oss-process=image%2Fcrop%2Cx_0%2Cy_1%2Cw_815%2Ch_614" width="398" title="" crop="0,0.0022,1,1" id="ud0844039" class="ne-image">

+ $ r<2M $“时间空间地位交换”：$ r $是类时的，而$ t $是类空的。
    - 只能往“未来”方向走，在$ r>2M $位置就是说时间往前走，不能往后走。$ r<2M $位置说就是可以往里走，不能往外走。
    - $ r = 2M $称为事件视界，因为在$ r>2M $的观察者看来，$ r<2M $内部事件的光线不能往外走，所以看不到。Horizon，类似于大海航行的时候看不到地平线以下的船只。

### 克尔时空
<img src="https://cdn.nlark.com/yuque/0/2026/png/2371504/1779084110969-af254097-fd9c-474e-bf4f-923d764fbef8.png" width="401" title="" crop="0,0,1,1" id="u4f62b4b7" class="ne-image">

+ 场方程真空稳态(stationary)轴对称解
    - 真空：外面
    - 稳态：度规每一个分量都不显含时间，但是$ g_{0i},g_{i0} $可以不为零。

<img src="https://cdn.nlark.com/yuque/0/2026/png/2371504/1779084759492-60eb8fd3-9caa-43a0-a90d-f51fc1bea1be.png" width="401" title="" crop="0,0,1,1" id="uc80ca7ed" class="ne-image">

+ 能层：在外视界和外无限红移面之间的区域
+ 为什么叫做能层：
    - 可以通过Penrose过程提取能量。Penrose过程依赖于负能轨道的存在。
    - 负能：动能+势能+静能的和是负数。日常情景，静能都很正，总能量不会是负数。但是在Kerr时空的能层中可以和为负数。
    - 能量来源于黑洞的自转能量。

+ 如果不考虑不确定性原理，所有的点粒子（半径为零）都完全位于其史瓦西半径以内，是黑洞，这显然是有问题的。
    - 因为如果是黑洞，除了质量、角动量和电荷之外的性质都会丢失，这显然是不合理的。
+ 认为波包在史瓦西半径以外，那么就不是黑洞。

#### 霍金辐射
<img src="https://cdn.nlark.com/yuque/0/2026/png/2371504/1779347641260-935e6efc-a28f-4785-8644-af406de7248b.png" width="401" title="" crop="0,0,1,1" id="u81886b84" class="ne-image">

<img src="https://cdn.nlark.com/yuque/0/2026/png/2371504/1779347686167-0ce5a394-8e3b-486d-8161-155bac0b3ebf.png?x-oss-process=image%2Fcrop%2Cx_4%2Cy_4%2Cw_1086%2Ch_815" width="400" title="" crop="0.0036,0.0048,1,1" id="u3c86e17d" class="ne-image">

+ 广义相对论：黑洞面积不减。
+ 弯曲时空中的量子场论：霍金辐射。
    - 弯曲时空中的量子场论是一种妥协的理论，将量子场论运用到弯曲时空中，并没有将广义相对论与量子场论真正结合起来形成量子引力理论。
+ 霍金辐射的温度（Bekenstein-Hawking温度）：

$ T = \frac{\hbar c^3}{8\pi GMk} $

+ 辐射功率（考虑到面积$ A \cdot \sigma T^4 $）：

$ \frac{dE}{dt} = \frac{\hbar^4c^8\sigma}{256\pi^3G^2k^4} \frac{1}{M^2} \propto M^{-2} $

    - 史瓦西半径与质量成正比，所以事件视界面积与质量平方成正比。
+ 辐射寿命（并不是寿命本身，只是一种用于估计的特征时间）：

$ \tau = \frac{Mc^2}{\dot E} \propto M^{3} $

    - 质量小的黑洞存在的时间是非常短的。
